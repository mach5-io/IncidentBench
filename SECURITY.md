# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in IncidentBench, please report it responsibly. **Do not open a public GitHub issue.**

Instead, please email **security@mach5.io** with:

- A description of the vulnerability
- Steps to reproduce it
- Any potential impact
- Suggested fix (if you have one)

We will acknowledge your report within 3 business days and aim to provide a resolution timeline within 10 business days.

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | Yes       |

## Disclosure Policy

- We will work with you to understand and resolve the issue before any public disclosure.
- We will credit reporters in the release notes (unless you prefer to remain anonymous).
- We ask that you give us reasonable time to address the issue before disclosing it publicly.
